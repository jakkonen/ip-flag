# IP Flag

Public IP & VPN country indicator for Firefox and Chromium browsers.

IP Flag answers one question at a glance: **from which country does this browser currently appear to access the Internet?**

## MVP

- toolbar country flag;
- independent IPv4 and IPv6 checks;
- country mismatch warning;
- ASN / organization;
- 60-second current-state cache;
- 24-hour GeoIP cache, max 50 IPs;
- automatic refresh with a configurable interval (default: 5 minutes);
- manual refresh;
- local check history and optional change notifications;
- unavailable public-IP checks are shown in the popup but are not stored as history events;
- round and rectangular flags generated locally from the same SVG source;
- no analytics, account, cloud sync, browsing-history access, or content-script access.

## Browsers

- Firefox
- Chrome
- Brave
- Edge
- other Chromium-compatible browsers

## Stack

- TypeScript
- Vite
- WebExtensions / Manifest V3
- a tiny local Firefox/Chromium API shim
- Vitest

## Network providers

### Public IP

- IPv4: `api.ipify.org`
- IPv6: `api6.ipify.org`

### GeoIP

- `api.ipapi.is/?q=<IP>`

The extension first determines IPv4/IPv6, then performs GeoIP only for IP addresses that are not already present in the local 24-hour cache.

## Development

### Requirements

- Node.js `20.19.0` or newer (or Node.js `22.12.0` or newer)
- npm, supplied with Node.js

The project has no required system services, developer backend, API keys, or environment variables.

### Reproducible Firefox build

From the root of this source archive:

```bash
npm ci
npm run typecheck
npm test
npm run build:firefox
```

The reproducible Firefox extension is written to `dist/firefox`. Package the *contents* of that folder so that `manifest.json` is at the root of the resulting ZIP file.

### General development

```bash
npm install
npm test
npm run typecheck
```

Build both browser targets:

```bash
npm run build
```

Or separately:

```bash
npm run build:firefox
npm run build:chromium
```

Outputs:

```text
dist/
├── firefox/
└── chromium/
```

## Load unpacked

### Firefox

1. Build with `npm run build:firefox`.
2. Open `about:debugging`.
3. Choose **This Firefox** → **Load Temporary Add-on**.
4. Select `dist/firefox/manifest.json`.

### Chrome / Brave

1. Build with `npm run build:chromium`.
2. Open the browser extensions page.
3. Enable developer mode.
4. Choose **Load unpacked**.
5. Select `dist/chromium`.

## Cache model

```text
public IP check
      │
      ├── same IP / fresh state → reuse current state
      │
      └── IP found
             │
             ├── GeoIP cached < 24h → reuse GeoIP
             │
             └── new/expired IP → GeoIP request → cache
```

GeoIP cache keys are the normalized IP strings themselves, so IPv4 and IPv6 coexist naturally.

## Toolbar behavior

```text
IPv4 FI + IPv6 FI  → Finland flag
IPv4 only FI       → Finland flag
IPv6 only FI       → Finland flag
IPv4 DE + IPv6 FI  → warning icon
no public IP       → neutral IP icon
```

## Privacy

The extension does not request access to visited pages, tabs, cookies, browsing history, search queries, or account information.

It sends only the minimum network requests required to determine public IPv4/IPv6 and obtain country/network metadata for those addresses.
