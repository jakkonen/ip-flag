# سياسة خصوصية IP Flag

تاريخ السريان: 11 أغسطس 2026.

[English](privacy.html) · [Русский](privacy-ru.html)

IP Flag هي إضافة للمتصفح تعرض محلياً كيفية ظهور المتصفح على الإنترنت: عناوين IPv4/IPv6 العامة وبلد الخروج ومؤسسة الشبكة.

## البيانات التي تتم معالجتها

تتصل الإضافة بخدمات خارجية لتحديد عناوين IPv4 وIPv6 العامة للمتصفح، ثم ترسل هذه العناوين إلى خدمة GeoIP لتحديد البلد ومؤسسة الشبكة.

تستخدم النسخة الحالية:

- `api.ipify.org` لعنوان IPv4 العام؛
- `api6.ipify.org` لعنوان IPv6 العام؛
- `api.ipapi.is` للبلد وASN ومؤسسة الشبكة.

## البيانات التي لا تُجمع

لا تطلب IP Flag أو تصل إلى سجل التصفح أو عناوين URL التي تمت زيارتها أو محتوى الصفحات أو ملفات تعريف الارتباط أو طلبات البحث أو كلمات المرور أو بيانات الحساب أو الموقع الدقيق للجهاز.

لا تستخدم الإضافة التحليلات أو الإعلانات أو القياس عن بُعد أو المزامنة السحابية أو خادماً يديره المطور.

## التخزين المحلي ونقل البيانات

تُخزن حالة الشبكة الحالية ونمط العلم المحدد وذاكرة GeoIP صغيرة في التخزين المحلي للإضافة فقط. تُحتفظ الذاكرة المؤقتة لمدة تصل إلى 24 ساعة وبحد أقصى 50 عنوان IP.

يُرسل عنوان IP العام إلى الخدمات المذكورة فقط لتقديم الوظيفة الأساسية للإضافة، باستخدام HTTPS.

## التغييرات على هذه السياسة

ستُحدّث هذه الصفحة مع إصدار جديد من الإضافة إذا تغيرت معالجة البيانات بشكل جوهري.
