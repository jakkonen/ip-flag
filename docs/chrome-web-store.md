# Публикация в Chrome Web Store

## Перед первой публикацией

1. Соберите Chromium-версию:

   ```powershell
   npm run build:chromium
   ```

2. Проверьте расширение локально: откройте `chrome://extensions`, включите режим разработчика, нажмите **Load unpacked** и выберите папку `dist/chromium`.
3. Убедитесь, что в `dist/chromium/manifest.json` указана новая версия и что popup, значок, IPv4, IPv6 и предупреждение о несовпадении работают.
4. Создайте ZIP-архив, содержащий *файлы внутри* `dist/chromium`, а не саму папку верхнего уровня. Например:

   ```powershell
   Compress-Archive -Path dist/chromium/* -DestinationPath dist/ip-flag-chromium.zip -Force
   ```

`node_modules`, исходный код, тесты и файлы Firefox в архив не включаются.

## Первая публикация

1. Откройте [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole) под постоянным аккаунтом Google.
2. Зарегистрируйте аккаунт разработчика: примите соглашение и оплатите разовый регистрационный взнос. Аккаунт и email впоследствии нельзя просто заменить, поэтому используйте адрес, который контролируете. Подробности: [официальная инструкция](https://developer.chrome.com/docs/webstore/register).
3. В профиле заполните отображаемое имя издателя и подтвердите контактный email. Это обязательные поля для нового аккаунта: [настройка аккаунта](https://developer.chrome.com/docs/webstore/set-up-account).
4. Нажмите **New item**, загрузите `dist/ip-flag-chromium.zip` и заполните карточку: название, краткое и полное описание, категория, язык, иконка 128×128, хотя бы один скриншот и контактный email.
5. В разделе **Privacy practices** честно укажите, что расширение получает публичные IP-адреса и отправляет их провайдерам `ipify` и `ipapi.is` только для основной функции. Укажите URL опубликованной политики конфиденциальности. Текст-заготовка лежит в `PRIVACY.md`; перед подачей разместите его по постоянному публичному HTTPS-адресу, например в GitHub Pages.
6. Для первой проверки выберите видимость **Unlisted**. Ссылка позволит установить расширение вам и тестировщикам, но не появится в поиске. После проверки смените на **Public**. Режимы видимости описаны в [документации Chrome](https://support.google.com/chrome/a/answer/2714278?hl=en).
7. Отправьте на проверку и дождитесь решения. Статус отображается в Dashboard.

## Обновления

Перед каждым обновлением увеличивайте `version` в `package.json`, повторяйте сборку и загрузку нового ZIP в ту же карточку расширения. Не меняйте идентификатор расширения и не добавляйте разрешения без необходимости: Chrome требует минимально необходимый набор разрешений. См. [политику работы с пользовательскими данными](https://developer.chrome.com/docs/webstore/user_data).

## Что подготовить для IP Flag

- публичный URL `PRIVACY.md`;
- почту поддержки;
- иконку 128×128 (уже есть в проекте);
- 1–5 скриншотов popup и предупреждения о расхождении стран;
- краткое описание без неподтверждённых обещаний: расширение показывает публичные IPv4/IPv6 и страну выхода, а не выполняет тесты утечек или управляет VPN.
