# Версионирование и публикация изменений

## Правило проекта

Перед каждым новым push с изменениями в ветку `main` необходимо повысить версию расширения. Версия в `package.json` автоматически попадает в сгенерированный `manifest.json` при сборке, поэтому Chrome Web Store получит корректную новую версию пакета.

## Порядок работы

1. Завершить изменение и выполнить проверки.
2. Повысить версию командой `npm version`.
3. Отправить commit с обновлёнными `package.json` и `package-lock.json` вместе с изменениями в GitHub.
4. Собрать Chromium-пакет перед загрузкой в Chrome Web Store.

## Тип версии

- `npm version patch` — исправление или небольшое улучшение: `0.1.0` → `0.1.1`;
- `npm version minor` — новая совместимая функция: `0.1.0` → `0.2.0`;
- `npm version major` — несовместимое изменение: `0.1.0` → `1.0.0`.

По умолчанию используется `patch`. Для заметной новой функции перед повышением версии следует выбрать `minor`.
